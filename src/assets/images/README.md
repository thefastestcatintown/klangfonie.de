# Bildablage

Die unveränderten Ausgangsdateien liegen in `originals/`. Sie werden nicht manuell
überschrieben oder verkleinert. Astro erzeugt beim Build daraus responsive,
komprimierte WebP-Varianten; Bilder aus Sanity werden über die Sanity Image API
zugeschnitten und automatisch im passenden Browserformat ausgeliefert.

`originals/hero-daniela-handpan-2026-11-06.png`. Die vorherige Fassung bleibt als
`originals/hero-daniela-handpan.jpg` erhalten.
